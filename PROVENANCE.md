# Provenance

This file records authorship and reference boundaries for `ventura-agents`.

## Ventura-authored material

The ten business-agent prompt definitions, project-specific workflows, eval scripts and documentation in this repository are maintained as Ventura Labs AI project material unless a file states otherwise.

## References

Agents may cite public standards, methods, vendors or industry practices as references. Such references do not imply affiliation, certification or endorsement. Third-party text must not be copied or translated into this repository without recording the source and applicable terms.

## Eval boundaries

Current automated evals validate structural/contract requirements. They do not by themselves prove semantic quality, hallucination rate, task success or production readiness. Any future quantitative agent metric must identify dataset, model/runtime, version, evaluator and commit/release.

## Contribution rule

Before adding copied, translated or adapted third-party material, record upstream/source, URL, version/date when practical, license/terms, reuse type and affected files.
